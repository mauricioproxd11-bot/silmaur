Todo el código, la identidad visual y las demos en un paquete que puedes publicar en tu propio hosting.

Abrir la web ↗Probar el editor ↗Leer la guía completa
01

Configura tu contacto.

Abre public_html/config.js y añade tu WhatsApp comercial con el código de país. También puedes añadir tu correo. Los campos están vacíos para que completes tus datos reales.

02

Sube los archivos.

Copia el contenido de public_html a la carpeta web de tu hosting. index.html, config.js, los CSS/JS y assets deben quedar juntos. Guarda antes una copia de tu web anterior, si existe.

03

Abre tu dominio.

Activa HTTPS desde tu hosting. Comprueba que se esté sirviendo index.html, que abran las demos y que el contacto muestre tu número al preparar una solicitud.

04

Hazla tuya.

Abre tu web con ?editar=1 al final de la dirección. Al pie encontrarás el editor. Usa Descargar config.js y reemplaza ese archivo en el hosting para publicar tus cambios.

Sin instalaciones ni compilaciones.

El sitio usa HTML, CSS y JavaScript con sus recursos locales. No necesitas Node, npm ni base de datos en el hosting.

  • Las demos usan datos ficticios y guardan las pruebas en la sesión de la pestaña.
  • El formulario prepara un mensaje; el visitante decide enviarlo por WhatsApp o correo.
  • Las carpetas pruebas y extras y estas guías no necesitan subirse a la web pública.
  • extras/Version_Anterior.zip conserva el código de la primera versión.
Incluye código editable, tres demos, selector de módulos, adelantos, abonos, exportación CSV y pruebas de los cálculos. La guía completa explica el alcance y cada archivo.
